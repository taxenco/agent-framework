# Comparison criteria

Agree on the criteria before research starts and give the same list to every researcher.

## Default criteria

| Criterion | What to check |
|---|---|
| Purpose fit | Does it solve the stated need? |
| Maturity | Age, stability, version, adoption |
| Maintenance | Recent commits and releases, open issues |
| License | Type and restrictions |
| Ease of use | Setup effort, documentation quality |
| Ecosystem | Integrations, community, support |
| Risks | Lock-in, security, missing features |

## Rules

- Start from the defaults; add or remove criteria only for the task at hand and state why.
- Every option is judged on every criterion. A missing finding is "not found", not a blank.
- Keep the list under 10 criteria.
- Do not rank options at this stage; ranking belongs to the `synthesizer`.
