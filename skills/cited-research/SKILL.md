# Cited research

## Rules

1. Every factual claim has a source link next to it.
2. Prefer primary sources (official repo, documentation, release notes) over blog posts and summaries.
3. Open the source before citing it. Do not cite a page you have not read.
4. If a claim cannot be verified, mark it `Unverified` and say why. Never present it as fact.
5. Do not invent numbers, versions, dates, or features. Say "not found" instead.
6. Note the date or version a fact refers to when it can change (stars, releases, pricing).
7. If sources disagree, report both and name the sources.

## Format

`<claim> ([source](url))`

## Red flags

- A claim with no link.
- A link that was never opened.
- Wording like "widely used" or "best" with no evidence.
